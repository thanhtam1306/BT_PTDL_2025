# Bài tập Phân tích Dữ liệu 2025

## Mô tả
Repo này chứa các bài tập và dự án nhỏ về **Phân tích Dữ liệu (Data Analysis)**, bao gồm:
- Xử lý dữ liệu (Data Cleaning)
- Khám phá dữ liệu (Exploratory Data Analysis - EDA)
- Trực quan hóa dữ liệu (Data Visualization)
- Một số bài toán ứng dụng thực tế
- ...

Các bài tập được thực hiện bằng **Python** với các thư viện phổ biến như `pandas`, `numpy`, `matplotlib`, `seaborn`, ...
